# BUG-001: Login Succeeds with Incorrect Password

## Bug Summary

The application allows a user to log in with an incorrect password.

## Environment

* Application: Demo Login Application
* Browser: Not specified
* Test Type: Functional Testing

## Preconditions

A registered user account exists.

## Steps to Reproduce

1. Open the login page.
2. Enter a registered email address.
3. Enter an incorrect password.
4. Click the Login button.

## Expected Result

The application should reject the login attempt and display an appropriate error message.

## Actual Result

The application allows the user to log in despite the incorrect password.

## Severity

Critical - if confirmed in a real application, unauthorized access may be possible.

## Priority

High - investigate and fix promptly.

## Status

Open - Example scenario, not verified in a real application.

## Notes

This is a hypothetical bug report created for learning purposes. The issue has not been reproduced in a real application.
